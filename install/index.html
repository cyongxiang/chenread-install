BEFORE YOU START

开始前，准备好这三样。

  1. 小纸 Pico 与 USB 数据线

    使用能传输数据的线材（不少充电线只能供电）。连接稳定，烧录期间不要拔线。

  2. 支持 Web Serial 的电脑浏览器

    桌面版 Chrome 或 Edge，并通过 HTTPS 打开本页。手机浏览器暂不支持。

  3. 确认当前版本与备份

    先在设备「设置 → 关于」看清当前固件版本，决定要不要擦除；备份 TF 卡上的重要文件与阅读记录；确认型号为 RDP-G01-W（ESP32-S3 + 4.7″ 墨水屏，16MB Flash）。

WHAT'S NEW

0.4.7 更新了什么。

  • 🔧 修复「书籍目录被设成 System Volume Information」：部分设备的书籍目录被误指到 TF 卡根目录的 Windows 系统卷目录，下载的书、书号旁车、云缓存全跑进那个文件夹，而 books 是空的。本版开机自动检测，命中即改回 /sdcard/books 并写回设置；之后仍尊重手动选择的其它目录。已经在 SVI 里的旧书不会自动搬家，请用 U 盘模式把其中的 .epub / .wrid 复制到 books（勿格式化整卡）。
  • 🔧 微信读书书架后端加固（书架界面一行未改）：同步时跳过损坏记录、不再把坏字节画成乱码书名；写索引前整份读回校验，写坏了只丢临时文件、保住旧书架；会话写内部 NVS 失败不再误报「存储失败，请检查 TF 卡与空间」；同步无论成败都重读一次列表；用 .epub.wrid 书号旁车恢复「已下载」标记；FAT 残留 .bak 先清一次再改名。
  • 🔄 底栏「同步进度」改为「先拉后判」：0.4.4 先把本地进度 + 时长上传、再拉云端比对，云端被刷成本地后必然判定一致，二选一弹窗几乎不出现（即「点了没反应」）。本版先只读拉官方进度，只有云端与本地不同才弹「用云端 / 保留本地」；一致 / 云端无进度 / 失败超时各给明确提示；选「保留本地」时把本地较新的进度与时长补传云端，多设备同步才成立。
  • ✅ 阅读心跳上传完整保留：每 5 分钟自动传进度 + 时长、关书补尾报、失败自动重试、开机续传；手动锁屏或深睡不打断。
  • ⚠️ 升级请勿勾选「擦除设备」：四段全刷不含 NVS 分区，从 0.4.4 / 0.4.3 / 0.4.2 / 0.4.1 / 0.4.0 / 0.3.11 / 0.3.10 升级时勾了擦除会清掉微信读书登录态、WiFi 密码、阅读进度与最近阅读，需要重新扫码。从 0.3.9 及更早升级才必须勾。
  • 沿用 0.4.4/0.4.3 的 Anki 全融合：FSRS-6 科学遗忘曲线排复习、每日新卡 20 / 复习 200 双限额、错题本、数据写同名 .akf 伴随文件（原子写 + 校验）。以及 0.4.2 星瞳云二维码修复、0.4.1 跨文件脚注 + 阅读时长可靠同步。配套手机 APK 仍须官方 v1.5.2 / code 11。
  • ⚠️ 本版三项改动均完成编译验证但未经实机烧录，建议先在备用设备确认书籍目录、书架同步、同步进度二选一弹窗与心跳照常后再推广。新增代码许可「个人学习可、禁商用」。

IF ONLINE FAILS

在线刷不了时的备用办法。

下载升级 Bin 放 TF 卡，或取四段完整包用命令行刷。

下载 TF 卡升级 Bin ↓ 返回主页刷机区 ↗
  • TF 卡升级：把下载到的 Pico-update.bin 放到 TF 卡根目录，在设备上「设置 → 升级和恢复 → 系统升级」里点「安装 TF 卡升级包」。仅适用于 0.3.10 及以上；固件会检查升级包是否超过分区容量，老版本会被拒绝并提示「升级包超过固件分区容量」。

FAQ

你可能想知道。

点了按钮，找不到我的设备？

确认用的是能传数据的线，并关掉占用串口的其他程序（如串口监视器、烧录工具）。然后在小纸上进入「设置 → 升级和恢复 → BOOT 刷机」让它进入 BOOT 模式，再回来点按钮连接。若 COM 口在但连不上（深睡后 USB 挂死），在 Windows 设备管理器里禁用再启用该 USB 设备重新枚举即可，COM 号不变。

要勾选「擦除设备」吗？

0.3.9 及更早：必须勾，因为分区表要从 4MB 双槽换成 8MB 单槽，旧的内部 storage 需要重建。0.3.10 / 0.3.11 / 0.4.0 / 0.4.1 / 0.4.2 / 0.4.3 / 0.4.4 / 0.4.7：不要勾，才能保留设置、WiFi 与微信读书登录态。无论哪种情况，书籍和字体都在 TF 卡上，不会丢。

为什么从 0.3.9 及更早只刷应用会起不来？

0.4.7 应用镜像 4,424,144 字节，旧双槽分区的单个槽只有 4,194,304 字节，多出 228,960 字节会写到分区外面；同时分区表没换成 8MB 单槽，启动校验失败。表现就是黑屏、反复重启无效。用「全新烧录」四段全刷一次即可恢复。

我从 0.4.4 升上来，要清空设备吗？

不用。0.4.4 / 0.4.3 / 0.4.2 / 0.4.1 / 0.4.0 / 0.3.11 / 0.3.10 都是单槽 8MB 分区，分区表相同，升级只需刷应用（或用上方「下载 0.4.7 升级 Bin」经 TF 卡升级），不清内部 storage，设置、阅读进度、书签与笔记都保留。建议仍用上方网页四段全刷最稳。

刷完起不来，怎么救？

不用慌，书在 TF 卡里。重新用左侧「全新烧录」四段全刷一遍，并勾选「擦除设备」；连不上就先让设备进 BOOT 模式，或拔插电源冷启动。仍不行可用 esptool 命令行按 0x0 / 0x8000 / 0x10000 / 0xD10000 四段重刷。

手机或 Safari 能刷吗？

不能。网页刷机依赖 Web Serial，目前只有桌面版 Chrome / Edge 支持，且页面必须 HTTPS。

刷完之后，书和字体从哪来？

固件不带书籍和字体。把 EPUB / TXT 放进 TF 卡的 books，字体放进 fonts，也可以用 WiFi、热点或 USB 传输。
